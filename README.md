# 九天万界 · 修仙人生模拟器 (时间自流逝 · 沉浸修真版)

基于《九天万界·超高自由度真实修仙人生模拟器》世界模拟协议打造的轻量级放置与交互沙盘网页游戏。

---

## 🌟 核心特性

- **岁月自流逝（时空罗盘）**：
  - `[⏸️ 驻足]`：暂停时空流转，从容检阅状态、坊市采办、服用丹药。
  - `[▶️ 缓流]`：1月 / 1.5秒，安详观望日月轮转。
  - `[⏩ 飞梭]`：1月 / 0.6秒，光阴似箭，修为如流水飞涨。
  - `[⚡ 一梦十年]`：一键闭关推演十载（120个月），中途遇危急或关隘自动提前破关唤醒。
- **主修行策长期托管**：无需频繁点按，选定方针后角色自动履行职责：
  - 🧘 **【闭关吐纳】**：引气归元，稳步积累修为进度，偶发顿悟。
  - 🌿 **【采药寻宝】**：深山搜药，稳定兑换灵石碎银，触发灵草机缘。
  - 📜 **【差事兼修】**：替仙族照料药田灵田，安稳赚取资粮。
  - 🗺️ **【探幽历练】**：涉足凶险大泽与古墓废墟，争夺无主机缘（高风险高回报）。
  - 🍵 **【温养调元】**：受创时自动优先用药疗伤，痊愈后自转吐纳。
- **智能因果拦截（绝不无脑暴毙）**：
  - ⚡ 遭遇深山妖兽守护灵草，强制暂停并弹出决策卡片；
  - ⚔️ 遭遇劫道敌修，强制暂停并切入策略斗法决斗场；
  - 🛑 修为达到关隘圆满时，强制暂停提醒道友冲击境界；
  - ⚠️ 气血低于 35% 濒危时，强制悬停时空避免猝死；
  - ⏳ 寿元剩余不足 5 年时天道警钟响起。
- **无预设默认值 · 命格由天**：
  - 首启强制进入角色创建，支持完全自由输入、挑选灵根天赋，或一键【🎲 摇签·天命全随机】。
- **数据 100% 纯本地持久化**：
  - 所有数据完整保存于浏览器 LocalStorage 中，支持一键备份与跨设备导入天机码。
- **原生程序合成古风音效**：
  - Web Audio API 程序合成磬音、道钟、滴答齿轮音，纯零外部依赖。
