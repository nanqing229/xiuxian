# 九天万界 · 修仙人生模拟器 (点击选择交互版)

基于《九天万界·超高自由度真实修仙人生模拟器》世界模拟协议打造的轻量级纯前端单页小游戏。

---

## 🌟 核心特性

- **纯点击点选交互**：告别繁重的手动打字，通过可视化按钮与卡片进行修行、抉择、探索与决策。
- **开局即玩**：默认无缝承接你创建的角色 **「临川」**（26岁 · 炼气二层 · 木水土三灵根 · 栖霞镇采药散修）。
- **完整修真体系**：
  - 凡人、炼气一至十三层、筑基（前/中/后/圆满）、金丹真人。
  - 突破概率计算、反噬暗伤、寿元大限倒计时。
  - 体魄气血、丹田灵气、功法研读（《长春引气诀》）。
- **丰富玩法行动**：
  - 🧘‍♂️ **【闭关吐纳】**：引气入体，稳步提升修为关隘进度。
  - ⚡ **【破境冲关】**：冲击境界瓶颈，成则寿元威能大增，败则气血受损。
  - 🌿 **【山野采药】**：深入云林山脉外围峭壁，采摘赤血草，随机触发突发境遇事件。
  - 🗺️ **【探幽历练】**：涉足乱石窟与断魂涧，搜寻古修洞府遗泽或迎战凶恶妖狼。
  - 🏛️ **【坊市市集】**：前往百草堂购置避毒丸、凝血散、聚气丹或下品攻防法器。
  - 📜 **【接取差事】**：充任陆家药田看守或护送凡俗镖队，稳赚银两灵石。
  - 👥 **【交游因果】**：拜访孙掌柜、邻里阿牛、泼皮散修陈三、陆家执事，打探机密、送礼结善缘。
  - ⚔️ **【回合制斗法】**：砍劈、施放灵气锥、撒毒粉、服丹回血、灵巧闪避、亡命遁逃！
  - 📰 **【万界月报】**：世界自主推演演化，宗门争锋、妖兽动向、物价行情实时更新。
  - 🔄 **【轮回转世】**：寿元耗尽或意外陨落后，可重塑道胎、自由摇签定制下一世生平。
  - 💾 **【天机存档】**：浏览器本地自动保存，支持一键复制/导入 Base64 存档码。
  - 🔊 **【原生程序音效】**：基于 Web Audio API 实时合成，无需任何外部音频。
